# Business KPIs (Key Performance Indicators)

## 1. Overview

A Key Performance Indicator (KPI) is a measurable value used to evaluate how effectively a business, team, or process achieves a specific objective.

KPIs help organizations:
- Monitor business performance.
- Measure progress toward goals.
- Identify operational problems.
- Compare actual results with targets.
- Support data-driven decisions.

### 1.1 KPI vs Metric

A metric is any measurable value. A KPI is a metric selected because it directly measures progress toward an important business objective.

Example:

- Total website visits: Metric.
- Website conversion rate: KPI when the business objective is improving conversions.

Not every metric is a KPI.

### 1.2 Characteristics of a Good KPI

A useful KPI should be:
- Relevant to a business objective.
- Clearly defined.
- Measurable.
- Based on reliable data.
- Time-bound where appropriate.
- Actionable.

A KPI should have a clear calculation method and an agreed interpretation.

## 2. KPI Components

A well-defined KPI generally contains:

| Component | Description |
|---|---|
| KPI Name | Name of the performance indicator |
| Objective | What the KPI measures |
| Formula | Calculation method |
| Actual Value | Current measured result |
| Target | Expected performance |
| Variance | Difference between actual and target |
| Reporting Period | Time period being measured |
| Data Source | Source of the information |
| Owner | Person or team responsible |

Example:

**KPI:** Monthly Sales Revenue

- Objective: Measure monthly sales performance.
- Formula: Sum of sales revenue.
- Actual: ₹8,50,000.
- Target: ₹10,00,000.
- Variance: -₹1,50,000.
- Achievement: 85%.

## 3. KPI Calculations

### 3.1 Actual vs Target

Variance:

\[
\text{Variance} = \text{Actual} - \text{Target}
\]

Example:

Actual sales = ₹85,000

Target sales = ₹1,00,000

Variance = -₹15,000

Excel:

```excel
=B2-C2
```

Assume B2 contains Actual and C2 contains Target.

### 3.2 Target Achievement Percentage

\[
\text{Achievement \%} =
\frac{\text{Actual}}{\text{Target}} \times 100
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

Format the result as a percentage.

If the target is zero, the achievement percentage may be undefined. Do not interpret the zero returned by IFERROR as actual zero performance without checking the target.

### 3.3 Growth Percentage

\[
\text{Growth \%} =
\frac{\text{Current Period} - \text{Previous Period}}
{\text{Previous Period}} \times 100
\]

Excel:

```excel
=IFERROR((B2-C2)/C2,0)
```

Assume B2 contains the current period value and C2 contains the previous period value.

### 3.4 Average

\[
\text{Average} = \frac{\text{Sum of Values}}{\text{Count of Values}}
\]

Excel:

```excel
=AVERAGE(B2:B100)
```

### 3.5 Percentage of Total

\[
\text{Percentage of Total} =
\frac{\text{Category Value}}{\text{Total Value}} \times 100
\]

Excel:

```excel
=IFERROR(B2/SUM($B$2:$B$10),0)
```

## 4. Sales and Marketing KPIs

Sales and marketing KPIs measure revenue generation, customer acquisition, conversion, and sales effectiveness.

### 4.1 Total Sales Revenue

Measures the total revenue generated from sales during a period.

Formula:

\[
\text{Total Revenue} = \sum \text{Sales Revenue}
\]

Excel:

```excel
=SUM(E2:E100)
```

### 4.2 Total Orders

Measures the number of orders received.

Excel:

```excel
=COUNTA(A2:A100)
```

Use an order ID column that contains one valid ID per order.

### 4.3 Average Order Value (AOV)

Measures average revenue per order.

\[
AOV = \frac{\text{Total Revenue}}{\text{Total Orders}}
\]

Excel:

```excel
=IFERROR(SUM(E2:E100)/COUNTA(A2:A100),0)
```

### 4.4 Sales Growth Rate

Measures revenue growth compared with a previous period.

Excel:

```excel
=IFERROR((B2-C2)/C2,0)
```

### 4.5 Conversion Rate

Measures the percentage of leads or visitors that complete a defined conversion.

\[
\text{Conversion Rate} =
\frac{\text{Conversions}}{\text{Total Leads}} \times 100
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

Define what counts as a conversion before calculating this KPI.

### 4.6 Customer Acquisition Cost (CAC)

Measures the average cost of acquiring a new customer.

\[
CAC =
\frac{\text{Acquisition Costs}}{\text{New Customers Acquired}}
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

Acquisition costs may include advertising, marketing, and sales expenses, depending on the organization's definition.

### 4.7 Return on Marketing Investment (ROMI)

Measures the return generated by marketing activities.

One commonly used definition is:

\[
ROMI =
\frac{\text{Incremental Revenue} - \text{Marketing Cost}}
{\text{Marketing Cost}} \times 100
\]

Excel:

```excel
=IFERROR((B2-C2)/C2,0)
```

Here B2 is incremental revenue and C2 is marketing cost.

Revenue-based ROMI is not the same as profit-based ROI. Use the agreed business definition.

### 4.8 Customer Retention Rate

Measures the percentage of existing customers retained over a period.

\[
\text{Retention Rate} =
\frac{\text{Customers at End} - \text{New Customers}}
{\text{Customers at Start}} \times 100
\]

Excel:

```excel
=IFERROR((B2-C2)/A2,0)
```

Assume:
- A2 = Customers at start.
- B2 = Customers at end.
- C2 = New customers acquired during the period.

## 5. Financial KPIs

Financial KPIs help measure profitability, expenses, liquidity, and financial performance.

### 5.1 Total Revenue

```excel
=SUM(B2:B100)
```

### 5.2 Total Expenses

```excel
=SUM(C2:C100)
```

### 5.3 Net Profit

\[
\text{Net Profit} = \text{Total Revenue} - \text{Total Expenses}
\]

Excel:

```excel
=B2-C2
```

This simplified calculation assumes all relevant expenses are included.

### 5.4 Gross Profit

\[
\text{Gross Profit} = \text{Revenue} - \text{Cost of Goods Sold}
\]

Excel:

```excel
=B2-C2
```

### 5.5 Gross Profit Margin

\[
\text{Gross Profit Margin} =
\frac{\text{Gross Profit}}{\text{Revenue}} \times 100
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

Assume B2 is gross profit and C2 is revenue.

### 5.6 Net Profit Margin

\[
\text{Net Profit Margin} =
\frac{\text{Net Profit}}{\text{Revenue}} \times 100
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

### 5.7 Operating Expense Ratio

\[
\text{Operating Expense Ratio} =
\frac{\text{Operating Expenses}}{\text{Revenue}} \times 100
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

### 5.8 Budget Variance

\[
\text{Budget Variance} = \text{Actual Expense} - \text{Budget}
\]

Excel:

```excel
=B2-C2
```

A positive variance means spending exceeded the budget under this convention. For revenue or other KPIs, the interpretation may differ.

## 6. Human Resources KPIs

HR KPIs measure employee performance, hiring, attendance, and workforce stability.

### 6.1 Total Employees

```excel
=COUNTA(A2:A100)
```

Use unique employee IDs and exclude blank or duplicate records.

### 6.2 Employee Turnover Rate

A common simplified calculation is:

\[
\text{Turnover Rate} =
\frac{\text{Employees Who Left During Period}}
{\text{Average Headcount}} \times 100
\]

Average headcount:

\[
\text{Average Headcount} =
\frac{\text{Opening Headcount}+\text{Closing Headcount}}{2}
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

Here B2 is employees who left and C2 is average headcount.

### 6.3 Absenteeism Rate

\[
\text{Absenteeism Rate} =
\frac{\text{Absent Workdays}}
{\text{Available Workdays}} \times 100
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

The denominator should reflect the organization's attendance calculation policy.

### 6.4 Hiring Rate

A basic hiring count measures the number of employees hired during a period.

```excel
=COUNTIFS(B2:B100,">="&E2,B2:B100,"<="&F2)
```

Assume column B contains joining dates, E2 is the start date, and F2 is the end date.

### 6.5 Training Completion Rate

\[
\text{Training Completion Rate} =
\frac{\text{Employees Completing Training}}
{\text{Employees Required to Complete Training}} \times 100
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

## 7. Operations KPIs

Operations KPIs measure productivity, efficiency, quality, and delivery performance.

### 7.1 Production Output

Measures the total quantity produced.

```excel
=SUM(B2:B100)
```

### 7.2 Defect Rate

\[
\text{Defect Rate} =
\frac{\text{Defective Units}}{\text{Total Units Produced}} \times 100
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

### 7.3 On-Time Delivery Rate

\[
\text{On-Time Delivery Rate} =
\frac{\text{Orders Delivered on Time}}
{\text{Total Orders Delivered}} \times 100
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

### 7.4 Productivity

A basic productivity measure is:

\[
\text{Productivity} =
\frac{\text{Output}}{\text{Input}}
\]

Examples:
- Units produced per labor hour.
- Orders processed per employee.
- Tickets resolved per working day.

The unit of measurement must be clearly defined.

### 7.5 Capacity Utilization

\[
\text{Capacity Utilization} =
\frac{\text{Actual Output}}{\text{Available Capacity}} \times 100
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

## 8. Customer Service KPIs

Customer service KPIs measure support quality, speed, and customer satisfaction.

### 8.1 Customer Satisfaction Score (CSAT)

A common calculation is:

\[
CSAT =
\frac{\text{Positive Responses}}
{\text{Total Valid Responses}} \times 100
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

The organization must define which survey responses count as positive.

### 8.2 Average Resolution Time

\[
\text{Average Resolution Time} =
\frac{\text{Total Resolution Time}}
{\text{Number of Resolved Tickets}}
\]

Excel:

```excel
=IFERROR(SUM(B2:B100)/COUNT(B2:B100),0)
```

Ensure all time values use consistent units.

### 8.3 First Response Time

Measures the time between receiving a customer request and providing the first response.

```excel
=AVERAGE(C2:C100)
```

This assumes column C contains valid response-time values in a consistent unit.

### 8.4 First Contact Resolution Rate

\[
FCR =
\frac{\text{Issues Resolved on First Contact}}
{\text{Total Eligible Issues}} \times 100
\]

Excel:

```excel
=IFERROR(B2/C2,0)
```

## 9. KPI Analysis in Excel

### 9.1 SUMIFS for Conditional Revenue

Calculate revenue for a particular region.

```excel
=SUMIFS(E2:E100,B2:B100,"South")
```

Assume:
- Column E = Revenue.
- Column B = Region.

### 9.2 COUNTIFS for Conditional Orders

Count orders from a particular region.

```excel
=COUNTIFS(B2:B100,"South")
```

### 9.3 AVERAGEIFS for Conditional Performance

Calculate average revenue for a specific region.

```excel
=AVERAGEIFS(E2:E100,B2:B100,"South")
```

### 9.4 Monthly KPI Calculation

Use date boundaries to calculate monthly revenue.

```excel
=SUMIFS(
    E2:E100,
    A2:A100,">="&DATE(2026,1,1),
    A2:A100,"<"&DATE(2026,2,1)
)
```

Assume column A contains valid Excel dates and column E contains revenue.

Using an exclusive end date includes all times on the final day when the source contains date-time values.

## 10. KPI Comparison and Performance Status

KPIs become more useful when actual performance is compared with a meaningful reference.

Common comparisons:
- Actual vs target.
- Current month vs previous month.
- Current year vs previous year.
- Actual vs budget.
- Region vs region.
- Product vs product.

### 10.1 Performance Status

Example classification:

| Achievement | Status |
|---|---|
| 100% or higher | On Target |
| 80% to below 100% | Needs Attention |
| Below 80% | Below Target |

Excel:

```excel
=IF(B2>=1,"On Target",
   IF(B2>=0.8,"Needs Attention","Below Target"))
```

Here B2 contains the achievement ratio, such as 0.85 for 85%.

These thresholds are illustrative. Use the actual business rules.

### 10.2 KPI Conditional Formatting

Excel can highlight:
- Values above target.
- Values below target.
- Negative growth.
- High defect rates.
- Unusual changes.

Use conditional formatting rules that reflect the direction of the KPI.

Important: Higher is not always better. For defect rate, cost, or absenteeism, lower values may represent better performance.

## 13. Common KPI Calculation Mistakes

| Mistake | Correct approach |
|---|---|
| Incorrect denominator | Verify the KPI definition |
| Comparing different periods | Use matching reporting periods |
| Ignoring missing data | Inspect missing and invalid records |
| Mixing units | Standardize units |
| Wrong date boundaries | Use correct date filters |
| Dividing by zero | Handle undefined calculations |
| Treating all positive variances as good | Understand KPI direction |
| Using incorrect headcount | Define opening, closing, and average headcount |
| Counting duplicate IDs | Use unique business identifiers |
| Comparing incompatible data | Check scope and definitions |

## 14. Best Practices

1. Connect every KPI to a business objective.
2. Document the calculation formula.
3. Identify the source data.
4. Define the reporting period.
5. Establish realistic targets using approved business requirements.
6. Use consistent units and number formats.
7. Compare actual performance against meaningful references.
8. Check whether higher or lower values represent better performance.
9. Handle missing data and zero denominators carefully.
10. Validate calculations before presenting KPIs.
11. Avoid displaying too many KPIs on one dashboard.
12. Update KPI definitions when business rules change.

## 15. Excel AI Agent Instructions

When a user requests KPI calculations or analysis, the AI Agent should:

1. Identify the business domain.
2. Inspect the workbook and available columns.
3. Understand the requested KPI definition.
4. Identify the correct numerator and denominator.
5. Verify date ranges, filters, and units.
6. Ask for clarification when the formula or target is ambiguous.
7. Use the appropriate Excel formulas or data-analysis tools.
8. Handle missing values and division-by-zero cases.
9. Compare actual values with targets only when valid targets are provided.
10. Explain the calculation and interpretation.
11. Never invent missing KPI values or business targets.
12. Verify the result before presenting it.
